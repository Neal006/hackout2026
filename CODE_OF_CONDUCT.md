# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, argue about the code not the person, and keep numbers honest. Harassment of any kind is not tolerated.

Report unacceptable behaviour by opening an issue titled `conduct:` or by contacting any maintainer directly. Reports are handled privately.
